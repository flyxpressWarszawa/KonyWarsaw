**Wniosek:** aktualne odczyty potwierdzają działający rejestr statusów, ale **nie potwierdzają** automatycznego odbioru niniejszego archiwum przez Hermesa. Nie wysyłano nowego `msw-combo/enqueue`: dopuszczone operacje `engine.submit` / `ai2ai.dispatch` wymagają ustalenia właściwego schematu i docelowego odbiorcy; nie wolno domyślać się routing/ACK ani tworzyć duplikatów. Łącze GitHub PR pozostaje otwartym, odczytywalnym przekazaniem do właściwego kanału.

**Kolejny bezpieczny krok:** właściwy Hermes po autoryzowanym READ-ONLY GitHub fetch zapisuje `request_id + source_sha + storage_readback + recipient_ack` w istniejącej prywatnej kolejce; do tego czasu `NOT_VERIFIED`.

Nie zmieniono cen, płatności, VAT, uprawnień, CRON, satelitów ani konfiguracji serwerów. Nie ujawniać prywatnych identyfikatorów witryn, tokenów, HMAC i danych klientów w publicznym repo.
